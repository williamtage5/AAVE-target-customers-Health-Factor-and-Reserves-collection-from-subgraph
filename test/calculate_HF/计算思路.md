### 🎯 1. 目标 (Goal)

计算用户 `0x084f247379c4106e2824686d3edb4a2fa837f38a` 在区块 `37495933` 时的健康因子。

**健康因子 (Health Factor) 公式:**
$$
\text{HF} = \frac{\sum (\text{CollateralBalance}_i \times \text{PriceInETH}_i \times \text{LiquidationThreshold}_i)}{\sum (\text{DebtBalance}_i \times \text{PriceInETH}_i)}
$$

* 分子是：该用户所有**启用为抵押品**的资产的（余额 * ETH价格 * 清算阈值）的总和。
* 分母是：该用户所有**债务**资产的（债务余额 * ETH价格）的总和。

### 📤 4. 计算输出 (Outputs & Calculation)

你将从上述查询中收到一个 JSON 格式的 `data.user.reserves` 列表。接下来，你需要在你的代码（例如 Python）中处理这个列表：

1.  **初始化变量:**
    * `total_collateral_eth = 0`
    * `total_debt_eth = 0`

2.  **遍历 `data.user.reserves` 列表:**
    对于 `for position in data.user.reserves:` 中的每一个 `position`：

    * **提取数据:**
        * `decimals = position.reserve.decimals`
        * `price_in_eth = float(position.reserve.oracleAsset.priceInEth) / (10**18)` (价格预言机通常使用 18 位小数)
    
    * **计算分母 (总债务):**
        * `debt_balance = float(position.currentTotalDebt) / (10**decimals)`
        * `total_debt_eth += debt_balance * price_in_eth`
    
    * **计算分子 (总抵押品 * 阈值):**
        * `is_collateral = position.usageAsCollateralEnabledOnUser`
        * if `is_collateral`:
            * `collateral_balance = float(position.currentATokenBalance) / (10**decimals)`
            * `threshold = float(position.reserve.reserveLiquidationThreshold) / 10000.0` (阈值通常是 4 位小数, e.g., 8500 -> 0.85)
            * `total_collateral_eth += collateral_balance * price_in_eth * threshold`

3.  **计算最终健康因子:**
    * if `total_debt_eth == 0`:
        * `health_factor = float('inf')` (无债务)
    * else:
        * `health_factor = total_collateral_eth / total_debt_eth`

这个 `health_factor` 值就是在区块 `37495933` 时，该用户在被清算前的健康因子。由于你是在清算前一个区块查询的，这个值应该非常接近 1.0（例如 0.998...）。
