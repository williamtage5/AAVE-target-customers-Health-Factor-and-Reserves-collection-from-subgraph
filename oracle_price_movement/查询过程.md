

### 查询可查询币种的名称以及id

```
{
  reserves(first: 10, orderBy: symbol, orderDirection: asc) {
    id
    name
    symbol
  }
}
```

1.  **正确的查询目标:** 您这次直接查询了 `reserves` 实体。这个实体代表 Aave 池中配置的**每一个独立资产储备** 。
2.  **唯一的结果:** `reserves` 查询返回的结果列表中的每一项都对应一个不同的资产，因此您看到了像 AAVE, EURC, GHO, USDC, WETH 等不同的币种，没有重复。
3.  **排序和限制:** `orderBy: symbol` 和 `orderDirection: asc` 确保了结果按字母顺序排列，`first: 10` 则限制了只返回前 10 个结果。

* 如果您想获取**所有**可用的币种，而不仅仅是按字母顺序排列的前 10 个，您可以**增加 `first` 的值**（例如 `first: 100`）或者完全**移除 `first` 参数**（但这可能会返回大量数据，需要注意分页处理）。

## 获取某个资产

```
{
  reserveParamsHistoryItems(
    where: {reserve: "0x42000000000000000000000000000000000000060xe20fcbdbffc4dd138ce8b2e6fbb6cb49777ad64d", timestamp_gte: 1759268532, timestamp_lte: 1761543995}
    orderBy: timestamp
    orderDirection: asc
  ) {
    id
    priceInEth
    priceInUsd
    reserve {
      id
      name
      symbol
    }
    timestamp
    liquidityRate
    variableBorrowRate
    stableBorrowRate
    availableLiquidity
    totalCurrentVariableDebt
    totalPrincipalStableDebt
    utilizationRate
    totalLiquidity
  }
}
```
